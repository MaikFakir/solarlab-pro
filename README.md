# SolarLab Pro

Gemelo digital 3D del seguidor solar (Arduino). Modelo energetico con las tres formulas:

- `E = E_max * cos(beta - theta)`
- `E' = -E_max * sen(beta - theta)`
- `E'' = -E_max * cos(beta - theta)`

Incluye condicion ambiental, balance energetico (panel, lampara de jardin, motor SG90),
veredicto de viabilidad del giro y linea de tiempo del dia con reproduccion.

Abrir: https://maikfakir.github.io/solarlab-pro/
